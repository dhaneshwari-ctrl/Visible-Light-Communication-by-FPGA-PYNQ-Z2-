# FPGA-Based VLC System


## Overview
This project implements a Visible Light Communication (VLC) system in which digital data is transmitted from a transmitter FPGA to a receiver FPGA using visible light generated by an LED.
The data is organized into packets before transmission. Manchester encoding is used at the transmitter side to encode the digital data, and Manchester decoding is performed at the receiver side to recover the original data.
The system consists of an FPGA-based digital communication system and an optical transmission and reception circuit. The hardware includes an MCP1407-based transmitter stage, infrared/visible-light LEDs, a BPW34 photodiode receiver, an OPA381 transimpedance amplifier, and a TLV3501 comparator.
The project is being developed using the PYNQ-Z2 FPGA platform and AMD Vivado.

# System Architecture

The PYNQ-Z2 is based on the Zynq-7000 SoC architecture, which combines a dual core ARM Cortex-A9 Processing System (PS) with FPGA Programmable Logic (PL).
The system is divided into two main sections:

### Processing System (PS)

The Processing System contains the ARM processor part. In this project, Python and PYNQ are used on the PS side for software-level control, data handling, and communication with the FPGA logic.

### Programmable Logic (PL)

The Programmable Logic contains the FPGA-based hardware design implemented using Verilog HDL and Vivado IP blocks.
The PL side is responsible for implementing the high-speed hardware processing and communication functions, including VLC data processing, Manchester encoding and decoding, packetization, depacketization, audio processing, video processing, and peripheral interfaces.
PS and PL communicate through the interfaces provided by the Zynq Processing System and AXI-based peripherals.

# Custom VLC Communication Logic

The VLC communication functions are implemented using custom Verilog HDL modules.

Standard Vivado IP does not provide the complete Manchester encoding, decoding, and packet communication functionality required by this project. Therefore, custom RTL modules were developed.

The custom modules include:

### Serializer

Converts parallel data into a serial data stream for transmission.

### Deserializer

Converts the received serial data stream back into parallel data.

### Packetizer

Organizes data into packets before transmission.

### Depacketizer

Extracts the original payload data from received packets.

### Manchester Encoder

Converts the packet data into Manchester-coded data before optical transmission.

### Manchester Decoder

Recovers the original data from the received Manchester-coded signal.

# VLC Transmitter Hardware

The transmitter hardware consists of an FPGA-generated digital transmission signal followed by an LED driver stage.

The basic transmission path is:

    FPGA
      |
      v
    VLC TX Logic
      |
      v
    MCP1407 Driver
      |
      v
    LED
      |
      v
    Optical Signal

The MCP1407 is used as the transmitter driver stage to provide the required drive capability for the LED.

# VLC Receiver Hardware

The receiver converts the received optical signal back into a digital signal.

The receiver path is:

    LED Optical Signal
          |
          v
      Photodiode
          |
          v
        BPW34
          |
          v
        OPA381
          |
          v
    Transimpedance Amplifier
          |
          v
       TLV3501
          |
          v
    Digital FPGA Input
          |
          v
    Manchester Decoder

The BPW34 photodiode detects the optical signal. The OPA381 converts the photodiode current into a voltage signal, and the TLV3501 comparator converts the analog signal into a digital signal suitable for processing by the FPGA.
